# KeepReady Reference Knowledge Base

This directory contains structured scientific data, empirical formulas, calculation tables, and procedural checklists derived from authoritative public domain standards.

These files serve as the ground-truth data repository from which KeepReady compiles its internal offline SQLite reference tables and validation algorithms.

## Directory Structure

* food_and_nutrition/ — Shelf-life tiers, annual rations, oxygen absorber formulas, and packaging rules.
* water_and_sanitation/ — Disinfection chemical dosages, boiling altitude math, and field sanitation.
* communications/ — PACE matrix, LoRa mesh protocols, analog radio emergency hailing frequencies.
* medical_and_trauma/ — TCCC MARCH trauma algorithms and emergency medical supply lists.
* civil_defense_and_hazards/ — Oak Ridge fallout decay physics, shielding tables, and Nordic 7-day standards.
