# KeepReady Reference Knowledge Base

This directory contains structured scientific data, empirical formulas, calculation tables, and procedural checklists derived from authoritative public domain standards and tactical survival doctrine.

## Directory Structure

* [food_and_nutrition/](./food_and_nutrition/)

  - [cooking_methods_and_equipment.md](./food_and_nutrition/cooking_methods_and_equipment.md) — Off-grid preparation: thermal retention (Haybox/Wonderbag), pressure cooking, cold-soaking, and fuel burn rates.
